# 数据、分劈与 AI 代理值

`data_source_registry.csv` 记录原核算表、附件论文、AI 工作簿和独立企业资料。`sector_split_registry.csv` 保留实际执行的 13 部门分劈值，`dynamic_parameter_registry.csv` 列出配置参数与硬编码规则。

附件论文说明：采用 2018、2020、2023 年 42 部门非竞争型投入产出表，合并国产与进口使用后形成竞争型结构；分离系数为相关行业规模以上营业收入与母部门同口径营业收入之比；以同一转换矩阵实施行列比例拆分。缺失四位数行业时可用覆盖一致的三位数行业；仅 2020 年缺失时使用 2018、2023 年线性插值；三期都缺失的行业不纳入。

论文列示的年鉴版本已经记录，尚未提供每项分子分母的原始表页与单元格。附件包含信息服务相关细分部门，当前 13 个决策部门并不包含这些部门。附件的规模表不用于覆盖现有矩阵或作为独立验证数据。使用未来资料插值的 2020 年结构具有事后信息，不能解释为实时预测输入。

## AI 指标的用途

工作簿是四类代理资料，未提供一项可直接使用的统一纵向 AI 综合指数：

- 任务暴露：2024 年职业构成加权 AIOE；存在负值，不是采用概率。
- 招聘：2024 年招聘渗透指标；无记录企业不自动视为没有 AI 招聘。
- 文本：2023 年年报 AI 词频的 `log(1+词频)`；反映披露或采用代理。
- 专利：本包计算 `log(1+引用专利数/(营收/1亿元))`；原表未明确年份，且 H5 没有记录。

环节聚合采用有效企业观测的算术均值。H3/H4/H5 合并时先合并企业记录再求均值；因此样本较多的 H3 权重较大。每个指标单独记录有效样本数，缺失不补零。相同 H 组赋予多个部门相同代理值，属于功能映射，不是各统计部门的直接观测。

设备 H1 对应部门 4、5、7；材料 H2 对应 1、2、3、6；H3/H4/H5 合并对应部门 8；H6 对应 9—13。这一粗映射未识别行业细类、产品份额和多业务归属。

本包将部门均值在部门之间作最小—最大相对缩放，用文本代理初始化 `ai_initial=0.2*score`，用专利代理设置 `absorption=0.3+0.4*score`。两个缩放区间均为情景假设；既不表示 2020 年真实采用率，也不估计 AI 投入转化效率。`ai_conversion` 没有被代理值替换。招聘和任务暴露单独留存，避免四项未经同年匹配便强行相加。

聚合得到的代理值可以用于异质性情景。取得采用、投入、互补资本与实际生产表现后，才可能进一步识别转化和吸收关系。

## 完整配置及代码数字清单

78条动态默认项与规则之外，task_parameter_registry.csv逐题、逐命名臂展开实际配置与向量；sector_role_registry.csv展开全部部门角色参数；code_literal_inventory.csv列出引擎中的全部数字字面量和代码行。后者包含维度、边界和数值常量，不能全算作经济参数。任务覆盖值优先于代码默认值，未在配置中覆盖的项目回落到代码或角色默认；新实验的场景覆盖值另见锁定划分和联合参数设计。
