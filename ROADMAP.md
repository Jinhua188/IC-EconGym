# IC-EconGym Roadmap

This roadmap is directional, not a promise of dates or acceptance at any venue.

## v0.3.0 — governed research release

Goals:

- stabilize the current 13+1-agent / 15-task benchmark surface;
- retain R1/G5 learning results including failures and inconclusive effects;
- expose locked evaluation splits and reporting rules;
- document joint parameter/rationing experiments and local external validation;
- add open-source governance, citation metadata and DOI archiving workflow.

## v0.4 — benchmark strengthening

Candidate priorities:

- reward and cash-account audit for R1;
- additional transparent optimization and MARL baselines;
- stronger out-of-distribution evaluation;
- expanded constraint-binding diagnostics;
- empirical parameter ranges with provenance;
- additional independent external-validation cases.

## v0.5 — network and agent expansion

Candidate priorities:

- firm-level real anchors with explicit edge-evidence status;
- accounting-preserving synthetic/partially observed network generation;
- product/technology substitutability constraints;
- LLM-agent baselines only under the same observation/action/evaluation protocol;
- scaling tests beyond the fixed 14-agent environment.

## Toward v1.0

A v1.0 claim should require substantially more than feature completeness. Target conditions include:

- stable task/evaluation APIs;
- documented benchmark governance and immutable test releases;
- broader independent validation across multiple dynamic mechanisms;
- clear separation of observed, calibrated, proxied and scenario-assigned quantities;
- reproducible reference baselines;
- explicit data and software licensing coverage.
