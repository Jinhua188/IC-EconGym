# Security policy

IC-EconGym is research software and is not intended to control operational semiconductor facilities, financial accounts or government systems.

## Reporting a vulnerability

Do **not** post credentials, tokens, private datasets, personally identifiable information or exploitable security details in a public Issue.

For ordinary reproducibility or numerical bugs, use the Bug Report Issue template.

For a security-sensitive problem, use GitHub's private vulnerability reporting button on the repository Security page when enabled. If private reporting is not enabled, contact the repository owner through a non-public channel shown on the owner's GitHub profile.

## Supported versions

Security fixes are normally applied to the latest development/release line. Research-prototype `v0.x` releases may not receive long-term security maintenance.
